# java-lotto-precourse

## 🙋‍♀️사용자 이용 가이드

### 1 단계. 구매금액 입력

콘솔에 문구가 뜨면 구매할 금액을 입력해주세요

```text
구입금액을 입력해 주세요.
```

<예시 입력>

```text
8000
```

<br>

<주의 사항>

**지정된 형식**에 따라 입력해 주세요!

- 비어 있는 이름 값은 입력할 수 없습니다
- 숫자가 아닌 값은 입력할 수 없습니다
- 처리 범위를 벗어난 (너무 큰 값)은 입력할 수 없습니다

- 1000원 미만은 입력할 수 없습니다
- 1000원 단위가 아닌 금액은 입력할 수 없습니다
- `10만원`을 초과해서 입력할 수 없습니다

<br>

구매한 갯수만큼 로또가 발행됩니다!

```text
8개를 구매했습니다.
[8, 21, 23, 41, 42, 43] 
[3, 5, 11, 16, 32, 38] 
[7, 11, 16, 35, 36, 44] 
[1, 8, 11, 31, 41, 42] 
[13, 14, 16, 38, 42, 45] 
[7, 11, 30, 40, 42, 43] 
[2, 13, 22, 32, 38, 45] 
[1, 3, 5, 14, 22, 45]
```

<br>

### 2단계. 당첨 번호 입력

콘솔에 문구가 뜨면 당첨번호를 입력해주세요.

```text
당첨 번호를 입력해 주세요.
```

<예시 입력>

```text
1,2,3,4,5,6
```

<br>

<주의 사항>

- 공백으로만 이루어진 값은 입력할 수 없습니다
- 지정된 형식(숫자, 구분자) 외에는 입력할 수 없습니다

- 1-45 사이가 아닌 번호는 입력할 수 없습니다
- 숫자의 갯수는 `6`개여야 합니다!

<br>

### 3단계. 보너스 번호 입력

콘솔에 문구가 뜨면 보너스 번호 입력해주세요.

```text
보너스 번호를 입력해 주세요.
```

<예시 입력>

```text
11
```

<주의 사항>

- 숫자가 아닌 값은 입력할 수 없습니다
- 공백으로만 이루어진 값은 입력할 수 없습니다
- 당첨번호와 중복된 숫자는 입력할 수 없습니다
- 1-45 사이가 아닌 번호는 입력할 수 없습니다

<br>

### 1단계~3단계. 재입력

잘못된 값을 입력할 경우, 예외 문구가 뜹니다! 다시 값을 입력해 주세요.

<예시>

```text
[ERROR] 숫자만 입력할 수 있습니다.
보너스 번호를 입력해 주세요.
```

<br>

### 4단계. 당첨 통계 발표

당첨된 등수 별 통계와 최종 수익률이 출력됩니다!

```text
당첨 통계
---
3개 일치 (5,000원) - 1개
4개 일치 (50,000원) - 0개
5개 일치 (1,500,000원) - 0개
5개 일치, 보너스 볼 일치 (30,000,000원) - 0개
6개 일치 (2,000,000,000원) - 0개
총 수익률은 62.5%입니다.
```

## 개발 기능 목록

#### ⏺️ 입력 기능(with 형식 검증)

1. 로또 구입 금액

- [X] 로또 구입 금액을 입력받는다

- [x] 숫자 형식이 아니면 예외를 발생한다
- [x] 공백이면 예외를 발생한다
- [x] null 값이면 예외를 발생한다

2. 당첨 번호

- [X] 당첨 번호를 입력받는다

- [x] 제시된 형식(숫자 + 구분자) 이 아니면 예외를 발생한다
- [x] 공백이면 예외를 발생한다
- [x] null 값이면 예외를 발생한다

3. 보너스 번호

- [X] 보너스 번호를 입력받는다

- [x] 숫자 형식이 아니면 예외를 발생한다
- [x] 공백이면 예외를 발생한다
- [x] null 값이면 예외를 발생한다

<br> 

#### ⏺️ 파싱 기능

- [x] 입력받은 값을 정수 타입으로 변환한다
- [x] 지정된 구분자로 잘라 숫자 리스트로 파싱한다

#### ⏺️ 로또 구매 기능

1. 금액

- [x] **<예외>** 1000원 미만은 예외를 발생한다
- [x] **<예외>** 1000원 단위가 아닌 금액은 예외를 발생한다
- [x] **<예외>** `10만원`을 초과하면 예외를 발생한다

2. 로또 발매

- [x] 1000원 단위로 로또 갯수를 구한다
- [x] 중복되지 않은 정수 6개를 랜덤으로 뽑는다
- [x] 이를 로또 갯수만큼 반복하여 뽑는다

- [x] 로또 숫자의 갯수가 6개가 아니면 예외를 발생한다
- [x] 숫자끼리 중복되는 값이 있으면 예외를 발생한다
- [x] 1-45 사이의 값이 아니면 예외를 발생한다

<br> 

#### ⏺️ 추첨 기능

1. 당첨 번호

- [x] 입력된 갯수가 6개가 아니면 예외를 발생한다
- [x] 숫자들에 중복되는 값이 있으면 예외를 발생한다
- [x] 1-45 사이의 값이 아니면 예외를 발생한다

2. 보너스 번호

- [x] 1-45 사이의 값이 아니면 예외를 발생한다
- [x] 당첨 번호 숫자와 중복되면 예외를 발생한다

3. 당첨 계산

- [x] 일치하는 로또 번호와 당첨 번호 갯수를 구한다
- [x] 로또 번호와 보너스 번호가 일치하는지 확인한다
- [X] 중복되는 갯수, 보너스 일치 여부에 해당하는 등수를 찾는다
- [x] 구매한 로또들에 대해 등수와 갯수를 구한다
- [x] 수익률을 구한다

<br>

#### ⏺️ 출력 기능

1. 구매한 로또

- [x] 구매수량과 번호를 출력한다
- [x] 번호는 오름차순으로 정렬한다

2. 당첨 내역

- [x] 당첨 기준, 금액, 당첨된 횟수를 출력한다
- [x] 계산된 수익률을 출력한다
- [x] 둘째 자리에서 반올림한 형식으로 출력한다
- [x] 자릿수를 구분하여 출력한다

<br> 

#### ⏺️ 재입력 요청 기능

- [x] 입력값에 대해 예외가 발생하면, 에러 문구를 출력한다
- [x] 예외는 `[ERROR]`로 시작하도록 출력한다
- [x] 다시 입력을 요청받는다
