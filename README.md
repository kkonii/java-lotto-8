# java-lotto-precourse

## 개발 기능 목록

#### ⏺️ 입력 기능(with 형식 검증)

1. 로또 구입 금액

- [ ] 로또 구입 금액을 입력받는다

- [ ] 숫자 형식이 아니면 예외를 발생한다
- [ ] 공백이면 예외를 발생한다

2. 당첨 번호

- [ ] 당첨 번호를 입력받는다

- [ ] 제시된 형식(숫자 + 구분자) 이 아니면 예외를 발생한다
- [ ] 공백이면 예외를 발생한다

3. 보너스 번호

- [ ] 보너스 번호를 입력받는다

- [ ] 숫자 형식이 아니면 예외를 발생한다
- [ ] 공백이면 예외를 발생한다

<br> 

#### ⏺️ 로또 구매 기능

1. 금액

- [ ] **<예외>** 1000원 미만은 예외를 발생한다
- [ ] **<예외>** 1000원 단위가 아닌 금액은 예외를 발생한다

2. 로또 발매

- [ ] 1000원 단위로 로또 갯수를 구한다
- [x] 중복되지 않은 정수 6개를 랜덤으로 뽑는다
- [x] 이를 로또 갯수만큼 반복하여 뽑는다

- [x] 로또 숫자의 갯수가 6개가 아니면 예외를 발생한다
- [x] 숫자끼리 중복되는 값이 있으면 예외를 발생한다
- [x] 1-45 사이의 값이 아니면 예외를 발생한다

<br> 

#### ⏺️ 추첨 기능

1. 당첨 번호

- [x] 입력된 갯수가 6개가 아니면 예외를 발생한다
- [x] 숫자들에 중복되는 값이 있으면 예외를 발생한다
- [x] 1-45 사이의 값이 아니면 예외를 발생한다

2. 보너스 번호

- [x] 1-45 사이의 값이 아니면 예외를 발생한다
- [ ] 당첨 번호 숫자와 중복되면 예외를 발생한다

3. 당첨 계산

- [x] 일치하는 로또 번호와 당첨 번호 갯수를 구한다
- [x] 로또 번호와 보너스 번호가 일치하는지 확인한다
- [X] 중복되는 갯수, 보너스 일치 여부에 해당하는 등수를 찾는다
- [ ] 발매된 로또 모두 등수를 찾고, 갯수를 계산한다
- [ ] 수익률을 구한다

<br>

#### ⏺️ 출력 기능

1. 구매한 로또

- [ ] 구매수량과 번호를 출력한다
- [ ] 번호는 오름차순으로 정렬한다

2. 당첨 내역

- [ ] 당첨 기준, 금액, 당첨된 횟수를 출력한다
- [ ] 계산된 수익률을 출력한다
